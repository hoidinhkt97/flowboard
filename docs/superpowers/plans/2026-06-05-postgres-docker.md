# Phase 7: PostgreSQL Migration + Docker Compose

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace SQLite with PostgreSQL in production, create the first Alembic migration, and update docker-compose to run the full stack (agent + frontend + postgres + minio) with a single `docker compose up`.

**Architecture:** Tests keep SQLite + `metadata.create_all` (fast, zero config). Production uses `FLOWBOARD_DATABASE_URL=postgresql+psycopg://...`. `init_db()` branches: runs `alembic upgrade head` on postgres, `metadata.create_all` on SQLite. Agent entrypoint runs migration then starts uvicorn. MinIO provides S3-compatible storage in the compose stack.

**Tech Stack:** PostgreSQL 16, Alembic (already wired in `migrations/env.py`), psycopg (already in requirements.txt), MinIO (S3-compatible), Docker Compose v2.

---

## Design notes

- **Tests stay on SQLite.** `conftest.py` overrides `FLOWBOARD_DATABASE_URL` to a temp sqlite path. Do not change this.
- **`init_db()` is the branch point.** `_is_sqlite` bool already exists in `session.py`. When False, run `alembic upgrade head`.
- **MinIO is S3-compatible.** Set `FLOWBOARD_S3_ENDPOINT=http://minio:9000` so boto3 hits MinIO.
- **`s3_key` column** (Phase 5) must appear in the migration. Autogenerate includes it if Phase 5 is merged; add manually otherwise.
- **Naming locked:** migration `0001_initial_schema.py`; compose services `db`, `minio`, `minio-init`; bucket `flowboard`.

## Task 2: Update init_db() to run Alembic on postgres

**Files:**
- Modify: `agent/flowboard/db/session.py`

- [ ] **Step 1: Extract legacy SQLite fix into private helper**

In `agent/flowboard/db/session.py`, add this function before `init_db()`:

```python
def _sqlite_targeted_migration() -> None:
    from sqlalchemy import inspect
    from flowboard.db import models  # noqa: F401

    with engine.connect() as conn:
        insp = inspect(conn)
        if insp.has_table("asset"):
            cols = {c["name"] for c in insp.get_columns("asset")}
            if "url" not in cols:
                models.Asset.__table__.drop(conn, checkfirst=True)
                conn.commit()
```

- [ ] **Step 2: Replace init_db() body**

```python
def init_db() -> None:
    if _is_sqlite:
        _sqlite_targeted_migration()
        from flowboard.db import models  # noqa: F401
        SQLModel.metadata.create_all(engine)
    else:
        import os
        from alembic import command
        from alembic.config import Config
        ini_path = os.path.abspath(
            os.path.join(os.path.dirname(__file__), "..", "..", "alembic.ini")
        )
        alembic_cfg = Config(ini_path)
        command.upgrade(alembic_cfg, "head")
```

## Task 4: Update docker-compose.yml

**Files:**
- Modify: `docker-compose.yml`

- [ ] **Step 1: Replace docker-compose.yml**

Replace the full file with:

```yaml
services:

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: flowboard
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-dev-change-in-prod}
      POSTGRES_DB: flowboard
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U flowboard"]
      interval: 5s
      timeout: 3s
      retries: 10
      start_period: 10s
    restart: unless-stopped
    networks:
      - flowboard

  minio:
    image: minio/minio:latest
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: ${MINIO_ROOT_USER:-flowboard}
      MINIO_ROOT_PASSWORD: ${MINIO_ROOT_PASSWORD:-dev-change-in-prod}
    volumes:
      - minio_data:/data
    ports:
      - "127.0.0.1:9001:9001"
    healthcheck:
      test: ["CMD", "mc", "ready", "local"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 15s
    restart: unless-stopped
    networks:
      - flowboard

  minio-init:
    image: minio/mc:latest
    depends_on:
      minio:
        condition: service_healthy
    entrypoint: >
      sh -c "
        mc alias set local http://minio:9000 $${MINIO_ROOT_USER:-flowboard} $${MINIO_ROOT_PASSWORD:-dev-change-in-prod} &&
        mc mb --ignore-existing local/flowboard &&
        mc anonymous set none local/flowboard &&
        echo bucket ready
      "
    networks:
      - flowboard

  agent:
    build:
      context: ./agent
    environment:
      FLOWBOARD_STORAGE: /app/storage
      FLOWBOARD_DATABASE_URL: postgresql+psycopg://flowboard:${POSTGRES_PASSWORD:-dev-change-in-prod}@db:5432/flowboard
      FLOWBOARD_JWT_SECRET: ${FLOWBOARD_JWT_SECRET:?Set FLOWBOARD_JWT_SECRET (openssl rand -hex 32)}
      FLOWBOARD_ENCRYPTION_KEY: ${FLOWBOARD_ENCRYPTION_KEY:?Set FLOWBOARD_ENCRYPTION_KEY (see .env.example)}
      FLOWBOARD_S3_ENDPOINT: http://minio:9000
      FLOWBOARD_S3_BUCKET: flowboard
      FLOWBOARD_S3_ACCESS_KEY: ${MINIO_ROOT_USER:-flowboard}
      FLOWBOARD_S3_SECRET_KEY: ${MINIO_ROOT_PASSWORD:-dev-change-in-prod}
      FLOWBOARD_S3_REGION: us-east-1
    volumes:
      - ./data/storage:/app/storage
      - ./data/codex:/root/.codex
      - ./data/flowboard:/root/.flowboard
    ports:
      - "8101:8101"
    depends_on:
      db:
        condition: service_healthy
      minio-init:
        condition: service_completed_successfully
    restart: unless-stopped
    networks:
      - flowboard

  frontend:
    build:
      context: ./frontend
    ports:
      - "3000:80"
    depends_on:
      agent:
        condition: service_healthy
    restart: unless-stopped
    networks:
      - flowboard

networks:
  flowboard:
    driver: bridge

volumes:
  postgres_data:
  minio_data:
```
